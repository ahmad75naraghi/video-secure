پخش امن ویدیو با رمزنگاری HLS AES-128، واترمارک کاربر و پشتیبانی از LearnDash.

== Description ==

پلاگین وردپرسی برای پخش ویدیوهای دوره‌های آموزشی با محافظت در برابر دانلود ساده و انتشار غیرمجاز.

* رمزنگاری AES-128 روی سگمنت‌های HLS
* ذخیره‌ی ویدیو و کلیدها بیرون از web root و تحویل فقط از دروازه‌ی PHP با توکن امضاشده
* بررسی ثبت‌نام LearnDash برای هر درخواست (پلی‌لیست، سگمنت و کلید)
* متاباکس «ویدیوی امن این درس» + نمایش خودکار در درس و مبحث
* واترمارک نام، نام کاربری و ایمیل روی تصویر (Canvas) که متنش فقط از پاسخ نشست می‌آید
* عنوان ویدیو می‌تواند فارسی باشد؛ شناسه‌ی فایل‌ها پس از اولین ذخیره پایدار می‌ماند
* آپدیت امن از گیت با پشتیبان، preflight و بازگردانی
* **بدون هیچ وابستگی بیرونی**: hls.js و Plyr داخل پلاگین باندل شده‌اند

= محدودیت‌های شناخته‌شده =

* ضبط صفحه (OBS یا دوربین) قابل جلوگیری نیست؛ هدف، بازدارندگی و قابل ردیابی بودن است.
* فایل‌های قدیمی موجود در `uploads/secure_videos` باید یک‌بار از پنل به پوشه‌ی امن منتقل شوند.
* اگر وب‌سرور Nginx است، `.htaccess` اجرا نمی‌شود؛ مسیرهای رسانه را در کانفیگ Nginx هم ببندید.
* برای تحویل پرحجم، تعریف `FALNIC_ACCEL_PREFIX` و `X-Accel-Redirect` توصیه می‌شود.

== Installation ==

1. پوشه‌ی پلاگین را در `wp-content/plugins/` قرار دهید.
2. از پیشخوان وردپرس فعال کنید.
3. `ffmpeg` باید روی سرور نصب و تابع `exec()` فعال باشد.
4. به «ویدیوهای امن → تنظیمات» بروید و وضعیت سیستم را بررسی کنید.

== Frequently Asked Questions ==

= آیا فایل‌ها از CDN بارگذاری می‌شوند؟ =
نه. تمام CSS و JS (شامل hls.js و Plyr) داخل پلاگین هستند.

= چرا ویدیو در Safari پخش نمی‌شود؟ =
مسیر پلی‌لیست باید با HTTPS در دسترس باشد و پاسخ با Content-Type درست برگردد.
